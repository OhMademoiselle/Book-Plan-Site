# Book-Plan-Site

Сайт для разработки сюжета книги.
Создавайте текстовые блоки, таблицы, заголовки, карточки и объединяйте их. Данные сохраняются в базе данных, но для надежности время от времени экспортируйте json-файл и сохраняйте себе.

Ссылка на сайт: 
https://ohmademoiselle.github.io/Book-Plan-Site/
